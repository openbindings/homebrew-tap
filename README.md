# OpenBindings Homebrew Tap

Homebrew casks for [OpenBindings](https://openbindings.com) tools.

## Install

```sh
brew install openbindings/tap/ob
```

## Available Casks

| Cask | Description |
|------|-------------|
| `ob` | The OpenBindings CLI |

## Validation

Run `ruby -c Casks/ob.rb` to check cask syntax, as ordinary CI does. Binary
installation and release qualification remain part of the release process.
